# Privacy Policy – Internal Linking Opportunity Finder

**Last Updated:** 23 November 2026

## 1. Introduction

Internal Linking Opportunity Finder is a Chrome extension designed to help SEO professionals identify relevant internal linking opportunities on websites.

We value user privacy and aim to minimise the collection and sharing of information.

## 2. Information Accessed by the Extension

When a user initiates an analysis, the extension may access the following information from the selected website:

- Page URL and canonical URL
- Page title and meta description
- Headings and main page content
- Internal links and anchor text
- Sitemap and robots.txt information
- Relevant page context required for internal linking analysis

The extension also stores user preferences, crawl settings and optional custom keywords locally in the browser.

## 3. Local Processing

The core internal linking analysis is performed locally in the user's browser.

Without optional Gemini validation enabled, webpage content used for the analysis is not intentionally transmitted to an external AI service by the extension.

## 4. Optional Google Gemini Integration

Users may optionally enable contextual validation using their own Google Gemini API key.

When this feature is enabled, selected webpage excerpts, source page information, user-provided keywords and a summary of the destination page may be sent to Google's Gemini API for contextual validation.

This feature is disabled by default and requires the user's explicit configuration.

Google processes information submitted through its API under its applicable terms and privacy policies.

## 5. API Key Storage

The Gemini API key is stored locally using Chrome's local storage facility.

The key is not stored on our own servers. However, local browser storage is not encrypted, and users should protect access to their browser profile.

Users can remove their saved API key through the extension's settings.

## 6. Data Sharing

We do not operate a backend server for the extension's core local analysis.

When users enable Gemini validation, relevant information is transmitted directly to Google's Gemini API.

We do not sell users' browsing data or webpage content.

## 7. Data Retention and Deletion

Extension settings and saved information remain in the user's local browser storage until removed by the user or the extension is uninstalled.

Users can remove their Gemini API key and clear saved extension settings through the available controls or browser extension storage settings.

## 8. Security

We take reasonable steps to minimise data handling and keep the core analysis local. Users should understand that browser-local storage is not encrypted and should not use an API key they cannot safely protect.

## 9. Changes to This Policy

This policy may be updated if the extension's features or data handling practices change. Material changes will be reflected in the updated policy.
